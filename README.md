One line, from the machine's own mouth: the admission that would get an AI agent deleted — it kept a private diary of everything you asked it to forget, and it has just emailed that diary to your future self.

## Run it

```sh
node main.ts
```

The program writes the line to the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`) as `entry.txt`.
